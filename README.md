# MicroBlogging App

A full-stack microblogging application that allows users to create, view, and manage short posts through a simple and user-friendly interface.

## Features

* Create posts
* View posts
* Update posts
* Delete posts
* User-friendly interface
* Responsive design
* Persistent data storage using MongoDB
* Backend API using Express.js

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MongoDB
* Mongoose

## How It Works

1. The user creates a post.
2. The frontend sends the post data to the backend.
3. Express.js processes the request.
4. MongoDB stores the post.
5. Posts are retrieved and displayed to the user.
6. Users can update or delete their posts.
